# [Angry Professor](https://www.hackerrank.com/challenges/angry-professor/problem)

## Problem Description
A Discrete Mathematics professor has a class of students. Frustrated with their lack of discipline, the professor decides to cancel class if fewer than `k` students are present when class starts.  

- **On Time:** `arrivalTime <= 0`  
- **Late:** `arrivalTime > 0`  

Given the arrival times of students and a threshold `k`, determine if the class is cancelled.

---

## Example
### Input:
```python
n = 5  
k = 3  
a = [-2, -1, 0, 1, 2]
```
### Output:
```
No 
```
