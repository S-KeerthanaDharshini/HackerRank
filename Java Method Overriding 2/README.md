# [Java Method Overriding 2 (Super Keyword)](https://www.hackerrank.com/challenges/java-method-overriding-2-super-keyword/problem)
`Java OOP` | `Inheritance` | `Super Keyword` | `Easy`

## 📝 Problem Statement
Complete the MotorCycle class to:
1. Override the `toString()` method
2. Include output from both:
   - MotorCycle's own description
   - Parent class (Cycle) description using `super` keyword


## 📊 Expected Output
```java
Hello I am a motorcycle, I am a cycle with an engine.
My ancestor is a cycle who is a vehicle with pedals.
```
