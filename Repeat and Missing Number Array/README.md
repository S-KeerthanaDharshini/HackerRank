# Repeat and Missing Number Array
`Array` | `Math` | `Bit Manipulation` | `Medium`

## 📝 Problem Statement
Given a read-only array of size `n` containing numbers from 1 to `n` where:
- One number appears twice (A)
- One number is missing (B)

Return A and B in a list with A first. The solution must have O(n) time and O(1) space complexity.

## 🔢 Constraints
- Array contains integers from 1 to n (n = array length)
- Exactly one duplicate and one missing number
- Read-only array (cannot modify input)

## 📊 Example

**Input:** `[3, 1, 2, 5, 3]`  
**Output:** `[3, 4]`  
**Explanation:** 3 is repeated, 4 is missing
