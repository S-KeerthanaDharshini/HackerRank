# Compare the Triplets
`Arrays` | `Easy`

## 📝 Problem Statement
Compare Alice's and Bob's challenge ratings across three categories:
- Award 1 point to the person with higher rating in each category
- No points for ties
- Return scores as [Alice's score, Bob's score]

## 📊 Sample Input/Output

### Sample Input
```
5 6 7  // Alice's ratings (a)
3 6 10 // Bob's ratings (b)
```

### Sample Output
```
1 1    // [Alice's score, Bob's score]
```
