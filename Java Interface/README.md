# [Java Interface](https://www.hackerrank.com/challenges/java-interface/problem)
`Java` | `OOP` | `Easy`

## 📝 Problem Statement
Implement the `AdvancedArithmetic` interface by creating a `MyCalculator` class that calculates the sum of all divisors of a given number `n`.



## 📊 Example

### Input
```java
6
```

### Output
```java
I implemented: AdvancedArithmetic
12
```

**Explanation:** Divisors of 6 are 1, 2, 3, and 6. Their sum is 12.
