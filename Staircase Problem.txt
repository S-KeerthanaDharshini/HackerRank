Problem : Staircase 

Problem Link :https://www.hackerrank.com/challenges/staircase/problem

Staircase detail

This is a staircase of size n=4
    #
   ##
  ###
 ####

Its base and height are both equal to n. It is drawn using # symbols and spaces. The last line is not preceded by any spaces.

Write a program that prints a staircase of size n .

Print

Print a staircase as described above. No value should be returned.
Note: The last line is not preceded by spaces. All lines are right-aligned.

Input Format

A single integer,n, denoting the size of the staircase.

Sample Input

6 

Sample Output

     #
    ##
   ###
  ####
 #####
######
