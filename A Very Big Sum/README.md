# A Very Big Sum
`Arrays` | `Easy`

## 📝 Problem Statement
Calculate the sum of elements in an array where integers may be very large (up to 10¹⁰).

## 🔢 Constraints
- 1 ≤ n ≤ 10
- 0 ≤ arr[i] ≤ 10¹⁰

## 📊 Sample Input/Output

### Sample Input
```
5
1000000001 1000000002 1000000003 1000000004 1000000005
```

### Sample Output
```
5000000015
```
