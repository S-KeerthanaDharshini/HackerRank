# [Save the Prisoner](https://www.hackerrank.com/challenges/save-the-prisoner/problem)
`Mathematics` | `Easy`

## 📝 Problem Statement
A jail has `n` prisoners sitting in a circle (numbered 1 to n). The jailer distributes `m` treats starting from chair `s`. Determine which prisoner receives the last (bad) treat.

## 📊 Example

### Input
```
n = 4  // prisoners
m = 6  // treats
s = 2  // start chair
```

### Output
```
3
```

**Explanation:** Distribution order: 2→3→4→1→2→3. The 3rd prisoner gets the last treat.
