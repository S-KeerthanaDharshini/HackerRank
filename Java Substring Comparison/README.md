# [Java Substring Comparisons](https://www.hackerrank.com/challenges/java-string-compare/problem)
`Java Strings` | `Sorting` | `Easy`

## 📝 Problem Statement
Given a string `s` and an integer `k`, find:
1. The lexicographically smallest substring of length `k`
2. The lexicographically largest substring of length `k`

### Key Points:
- Lexicographical order follows dictionary sequence (A < B < ... < a < b < ... < z)
- Substrings must be exactly length `k`
- All possible contiguous substrings of length `k` should be considered

## 📊 Example

### Input
```
welcometojava
3
```

### Output
```
ava
wel
```
