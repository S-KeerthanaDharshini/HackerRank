# [Java Strings Introduction](https://www.hackerrank.com/challenges/java-strings-introduction/problem)
`Java Strings` | `Basic Operations` | `Easy`

## 📝 Problem Statement
Given two lowercase strings A and B, perform these operations:
1. Calculate the sum of their lengths
2. Compare them lexicographically (dictionary order)
3. Capitalize their first letters and print them space-separated

## 📊 Example

### Input
```
hello
java
```

### Output
```
9
No
Hello Java
```
