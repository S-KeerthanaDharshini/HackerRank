# Bill Division (Bon Appétit)
`Arrays` | `Easy`

## 📝 Problem Statement
Anna and Brian split a restaurant bill where:
- Anna didn't eat one item (at index `k`)
- They split the remaining bill equally
- Determine if Brian overcharged Anna and by how much

## 📊 Sample Input/Output

### Sample Input
```
4 1       # n=4 items, k=1 (0-based)
3 10 2 9  # bill items
12        # amount Brian charged Anna
```

### Sample Output
```
5
```
