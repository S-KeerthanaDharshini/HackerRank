# [Subarray Division](https://www.hackerrank.com/challenges/the-birthday-bar/problem)
`Arrays` | `Easy`

## 📝 Problem Statement
Given a chocolate bar with integer values, find the number of contiguous segments where:
- Segment length equals birth month `m`
- Segment sum equals birth day `d`

## 📊 Example

### Input
```
s = [2, 2, 1, 3, 2]  // chocolate squares
d = 4                // required sum
m = 2                // segment length
```

### Output
```
2
```

**Explanation:** Segments [2,2] and [1,3] both have length 2 and sum 4.
