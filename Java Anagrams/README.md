# [Java Anagrams](https://www.hackerrank.com/challenges/java-anagrams/problem)
`Strings` | `Easy`

## 📝 Problem Statement  
Two strings, `a` and `b`, are called **anagrams** if they contain the same characters in the same frequencies, regardless of order or case. Your task is to determine whether two given strings are anagrams of each other.


 The comparison should be **case-insensitive**. For example, the anagrams of CAT are CAT, ACT, tac, TCA, aTC, and CtA.

## 🖊️ Sample  Input:  
a = "anagram"  
b = "margana"  
## 👩🏻‍🏫Output:  
Anagrams 

## Explanation:
 "anagram" and "margana" contain the same characters with the same frequencies.
