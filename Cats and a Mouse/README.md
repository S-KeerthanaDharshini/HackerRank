# Cats and a Mouse
`Math` | `Easy`

## 📝 Problem Statement
Given positions of two cats (A and B) and a mouse (C) on a line, determine which cat reaches the mouse first when:
- Both cats move at equal speed
- Mouse doesn't move unless cats arrive simultaneously
- Return "Cat A", "Cat B", or "Mouse C"

## 📊 Sample Input/Output

### Sample Input
```
2        // q = 2 queries
1 2 3    // x=1, y=2, z=3
1 3 2    // x=1, y=3, z=2
```

### Sample Output
```
Cat B
Mouse C
```
