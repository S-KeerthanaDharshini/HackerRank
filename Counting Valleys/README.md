# Counting Valleys
`Strings` | `Easy`

## 📝 Problem Statement
Given a hike path consisting of 'U' (uphill) and 'D' (downhill) steps:
- Count the number of valleys traversed
- A valley is a sequence starting with 'D' below sea level and ending with 'U' back to sea level
- Hike always starts and ends at sea level

## 📊 Sample Input/Output

### Sample Input
```
8         // steps
UDDDUDUU  // path
```

### Sample Output
```
1         // valleys count
```
