# Breaking the Records
`Arrays` | `Easy`

## 📝 Problem Statement
Given an array of basketball scores, count how many times Maria breaks her:
1. **Highest score** record
2. **Lowest score** record

Records are established by the first game and updated whenever a new extreme is reached.

## 📊 Sample Input/Output

### Sample Input
```
9
10 5 20 20 4 5 2 25 1
```

### Sample Output
```
2 4  # (max breaks, min breaks)
```
