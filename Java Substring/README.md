# [Java Substring](https://www.hackerrank.com/challenges/java-substring/problem)
`Java Strings` | `Basic Operations` | `Easy`

## 📝 Problem Statement
Given a string `S` and two indices (`start`, `end`), print the substring from `start` (inclusive) to `end` (exclusive).

### Key Points:
- String indices are 0-based
- End index is exclusive (not included in result)
- Uses Java's `String.substring()` method

## 📊 Example

### Input
```
Helloworld
3 7
```

### Output
```
lowo
```
