# [Java Iterator](https://www.hackerrank.com/challenges/java-iterator/problem)
`Java Collections` | `Iterators` | `Easy`

## 📝 Problem Statement
Modify a method to print only elements occurring after the special string `"###"` in an ArrayList. The input ArrayList contains:
1. One or more integers
2. The string `"###"`
3. One or more strings

You can edit at most 2 lines in the given code.

## 📊 Example

### Input ArrayList
```java
[42, 10, "###", "Hello", "Java"]
```

### Output
```java
Hello
Java
```
