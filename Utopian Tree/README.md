# [Utopian Tree](https://www.hackerrank.com/challenges/utopian-tree/problem)
`Algorithms` | `Easy`

## 📝 Problem Statement
A Utopian Tree sapling (height = 1m) grows through alternating cycles:
- **Spring**: Doubles in height
- **Summer**: Grows by 1m

Given `n` growth cycles, determine the tree's final height.

## 📊 Sample Input/Output

### Sample Input
```
3
0
1
4
```

### Sample Output
```
1
2
7
```
