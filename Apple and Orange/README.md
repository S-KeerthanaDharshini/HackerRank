# Apple and Orange
`Arrays` | `Simulation` | `Easy`

## 📝 Problem Statement
Determine how many apples and oranges fall on Sam's house given:
- House location (s to t on x-axis)
- Apple tree position (a)
- Orange tree position (b)
- Lists of fruit fall distances

## 📊 Sample Input/Output

### Sample Input
```
7 11     # House [s, t]
5 15     # Apple tree (a), Orange tree (b)
3 2      # m apples, n oranges
-2 2 1   # Apple distances
5 -6     # Orange distances
```

### Sample Output
```
1  # Apples on house
1  # Oranges on house
```
