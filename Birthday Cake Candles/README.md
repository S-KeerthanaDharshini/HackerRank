# Birthday Cake Candles
`Arrays` | `Easy`

## 📝 Problem Statement
Given an array of candle heights, count how many candles are the tallest (maximum height).

## 📊 Sample Input/Output

### Sample Input
```
4         # n = 4 candles
3 2 1 3   # candle heights
```

### Sample Output
```
2         # Number of tallest candles
```
