# [Staircase](https://www.hackerrank.com/challenges/staircase/problem)
`Algorithms` | `Easy`

## 📝 Problem Statement
Given an integer `n`, print a right-aligned staircase of height and width `n` using `#` symbols and spaces.

## 📊 Sample Input/Output

### Sample Input
```
6
```

### Sample Output
```
     #
    ##
   ###
  ####
 #####
######
```
