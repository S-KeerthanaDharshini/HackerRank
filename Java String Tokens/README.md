# [String Tokens](https://www.hackerrank.com/challenges/java-string-tokens/problem)
`Java Strings` | `Regular Expressions` | `Medium`

## 📝 Problem Statement
Given a string `s` containing various characters, split it into tokens where:
- A token is one or more consecutive English letters (a-z, A-Z)
- Print the token count followed by each token on a new line

## 📊 Example

### Input
```
He is a very very good boy, isn't he?
```

### Output
```
10
He
is
a
very
very
good
boy
isn
t
he
```
