# [Time Conversion](https://www.hackerrank.com/challenges/one-week-preparation-kit-time-conversion/problem)
`Strings` | `Easy`

## 📝 Problem Statement
Given a time in **12-hour AM/PM format**, convert it to **24-hour military time**.

### Notes:
- `12:00:00AM` → `00:00:00`
- `12:00:00PM` → `12:00:00`

## 📊 Example

### Input
s = "07:05:45PM"

### Output
19:05:45
