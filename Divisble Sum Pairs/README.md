# [Divisible Sum Pairs](https://www.hackerrank.com/challenges/divisible-sum-pairs/problem)
`Arrays` | `Easy`

## 📝 Problem Statement
Given an array of integers and a positive integer `k`, count the number of pairs (i, j) where:
- i < j
- arr[i] + arr[j] is divisible by k

## 📊 Sample Input/Output

### Sample Input
```
6 3       // n=6, k=3
1 3 2 6 1 2  // array
```

### Sample Output
```
5         // number of valid pairs
```
