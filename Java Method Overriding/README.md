# [Java Method Overriding](https://www.hackerrank.com/challenges/java-method-overriding/problem)
`Java OOP` | `Inheritance` | `Easy`

## 📝 Problem Statement
Complete the Soccer class by overriding the `getNumberOfTeamMembers()` method to:
1. Maintain the same method signature
2. Print "Each team has 11 players in Soccer Class"


## 📊 Expected Output
```java
Generic Sports
Each team has n players in Generic Sports
Soccer Class
Each team has 11 players in Soccer Class
```
